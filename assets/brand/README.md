# Chaos brand assets

The Chaos mark belongs to the shared Heliantheon visual family: geometric construction, rounded strokes, strong negative space, and a single product accent.

| File | Purpose |
| --- | --- |
| `mark.svg` | Primary full-color vector mark |
| `mark-monochrome.svg` | Single-color mark for neutral surfaces |
| `icon-512.png` | Raster icon for platforms that do not accept SVG |
| `hero-ice.png` | Transparent ice-block hero for README and promotional use |

- Accent: `#545D6B`
- Keep clear space around the mark equal to at least one eighth of its width.
- Do not stretch, rotate, recolor, add effects, or combine the mark with another product emblem.
- Prefer the primary mark on white or very light neutral backgrounds; use the monochrome mark when color is unavailable.
- Use the ice-block hero at 256 px or larger, keep its canvas transparent, and do not use it as a favicon or small interface icon.
